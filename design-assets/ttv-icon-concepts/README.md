# TTV Box icon concepts

Four non-destructive application icon directions based on the current TTV Box interface:

- `ttv-prism-play`: closest to the current brand mark, with stronger depth and taskbar presence.
- `ttv-cinema-frame`: adds a screen/frame metaphor for the desktop cinema experience.
- `ttv-stream-orbit`: emphasizes aggregated media sources and direct streaming.
- `ttv-light-curtain`: uses layered light planes to suggest enhancement and cinematic rendering.

The SVG files are the editable masters. The PNG files are 1024 x 1024 exports. `ttv-icon-concepts-preview.png` is a presentation sheet and `ttv-icon-size-check.png` verifies legibility at 32, 48, and 64 pixels; neither preview is intended for app packaging.
