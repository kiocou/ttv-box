# TTV 工程规范与验收测试用例

> **标准目标**：建立明确的性能基线、代码质量规范与覆盖多场景的严苛验收测试用例集。

---

## 1. 核心性能指标与验收基线 (Performance KPIs)

| 指标项 | 目标阈值 | 测试方法与验证条件 |
|---|---|---|
| **应用冷启动时间** | **≤ 3.0 秒** | 从双击可执行文件到主窗口完整渲染且可响应点击 |
| **本地视频首帧起播** | **≤ 1.0 秒** | 4K HEVC 100Mbps 码率本地 MKV 文件点击到画面渲染 |
| **光鸭直链首帧起播** | **≤ 3.5 秒** | 100Mbps 宽带环境下，光鸭云盘 4K 原画直链起播 |
| **长时间播放稳定性** | **8 小时连续播放** | 连续播放 4K 影片 8 小时无崩溃，内存增长 ≤ 100MB |
| **插帧画面平滑度** | **稳定 60 FPS** | 24FPS 电影插帧至 60FPS 丢帧率 ≤ 0.1% |
| **UI 交互帧率** | **稳定 60 FPS** | 海报墙快速滚动与窗口缩放无掉帧与卡顿 |

## 2. 验收测试用例矩阵 (Test Matrix)

### 2.1 格式与解码兼容性测试
- [ ] **视频编码**：H.264 (AVC)、H.265 (HEVC 8-bit / 10-bit Main 10)、AV1、VP9
- [ ] **封装容器**：MKV、MP4、TS、M2TS、MOV、AVI、WebM
- [ ] **音频解码**：AAC、AC3 (Dolby Digital)、E-AC3 (Dolby Digital Plus)、TrueHD (Atmos)、DTS-HD Master Audio、FLAC
- [ ] **字幕渲染**：内嵌 ASS/SSA 特效字幕、内嵌 PGS 图形字幕、外挂 SRT、WebVTT
- [ ] **HDR 直通**：HDR10、Dolby Vision (Profile 5 / 8.1 降级播放与色调映射)

### 2.2 云盘与网络容灾测试
- [ ] **弱网与断网重连**：播放在线直链时拔掉网线 5 秒后插回，播放器应平滑缓冲恢复，无死锁。
- [ ] **Token 失效重试**：模拟光鸭 Token 过期（服务端返回 401），客户端应静默调用 Refresh Token 并重试当前播放请求。
- [ ] **多清晰度无缝切换**：在线播放过程中切换 1080P 与 4K 档位，保留当前播放时间戳。

### 2.3 AI 画面增强测试
- [ ] **RIFE 插帧开关**：播放过程中实时开启/关闭 RIFE 插帧，画面不黑屏、音频不同步不漂移。
- [ ] **超分着色器挂载**：挂载 ArtCNN 着色器后，低分辨率画面边缘细节显著锐化。
- [ ] **显存溢出熔断**：在低显存设备上尝试超负荷插帧，系统自动降级并弹出友好提示，无崩溃。

### 2.4 安全合规与隐私审计
- [ ] 检查 `%APPDATA%` 与应用目录，**绝不存在明文 Token / 密码文件**。
- [ ] 尝试将 `ttv-store.db` 复制到其他 Windows 计算机上打开，DPAPI 加密凭据**无法被跨机解密**。
- [ ] 二进制代码中无任何硬编码第三方私钥或未经授权的商业鉴权后门。
