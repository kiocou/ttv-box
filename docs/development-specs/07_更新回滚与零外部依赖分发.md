# TTV 更新回滚与零外部依赖分发规范

> **目标**：实现 Windows 11 环境下的单安装包免环境配置分发，配合高安全性的 SHA-256 校验与崩溃自动回滚机制。

---

## 1. 零外部依赖打包标准 (NSIS Installer)

### 打包资源清单与目录规范
```text
TTV-Installer-v1.0.0-x64.exe (NSIS 打包产物，约 450MB)
  ├── ttv-cinema.exe                  # Tauri 2 / Rust 主程序
  ├── mpv-2.dll                       # libmpv 播放引擎动态库
  ├── resources/
  │   ├── ffmpeg/                     # FFmpeg n8.1 共享库与可执行文件
  │   ├── shaders/                    # ArtCNN, SSimDownscaler, adaptive-sharpen 着色器
  │   ├── vapoursynth/                # 内嵌 Python 3.12, VapourSynth, DirectML, RIFE ONNX
  │   └── fonts/                      # 内嵌字体资产
  └── icons/                          # 快捷方式与系统托盘图标
```

### 运行时排除策略 (Exclude Policy)
更新包与发布包中严格**排除**任何用户数据：
- 排除 `data/*.db`（SQLite 用户数据与媒体库）
- 排除 `data/kv` 与凭据存储
- 排除 `cache/`（图片海报、临时分片）
- 排除 `logs/` 与临时文件

## 3. 安全更新与原子替换状态机

```
[检查更新] ──▶ 获取 version.json ──▶ 版本比对 (isNewer)
   │
   ▼
[下载更新包] ──▶ 下载至临时目录 .update-staging/ ──▶ 计算本地 SHA-256
   │
   ├─ 哈希不匹配 ──▶ 立即删除损坏包并报错 (SHA-256 Mismatch)
   ▼
[快照备份] ──▶ 将当前运行核心备份至 .update-backup/
   │
   ▼
[原子替换] ──▶ 覆盖替换 resources/ 核心文件
   │
   ▼
[重启自检] ──▶ 启动新版本自检进程 (10秒健康探活)
   │
   ├─ 自检超时 / 崩溃 ──▶ 自动触发回滚: 从 .update-backup/ 恢复上一版本
   ▼
[更新成功] ──▶ 清理暂存与备份目录，记录更新日志
```

### 安全护栏约束 (Safety Guards)
1. **强制 SHA-256 校验**：若下载的增量包哈希与清单不符，立即物理抹除，拒绝加载。
2. **下载源可信限制**：仅允许下载来自官方 GitHub Releases 或已声明的 CDN 白名单域名。
3. **用户数据零破坏**：更新只作用于程序和资源目录，绝不触碰 SQLite 数据库文件与 DPAPI 凭据。
