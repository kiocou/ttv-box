# TTV 产品全景与版本路线规划规范

> **定位**：面向 Windows 11 的影院级桌面媒体中心与极速播放客户端，功能等价于 LumiPlayer，完全开源、单机运行、零外部运行时依赖。

---

## 1. 产品定位与核心价值

TTV 旨在打造一款集 **「网盘直连播放 + 本地/NAS 媒体中心 + AI 画面插帧超分 + 独立影院播放窗口」** 于一体的现代化高性能桌面媒体聚合播放器。

### 核心价值主张
1. **极致画质与性能**：基于 `libmpv` 与 Direct3D 11 渲染管线，结合内置 RIFE v4.25 光流补帧与 ArtCNN 神经网络超分，实现 24/30 FPS 到 60/120 FPS 实时平滑增强。
2. **多源聚合直连**：原生支持光鸭云盘（RFC 8628 Device-Code 扫码与短信验证码双通道），后续扩展主流网盘与 Emby/Jellyfin/Plex 媒体服务器。
3. **零外部环境依赖**：用户安装后无需预装 Node.js、Python、Java、MPV 或 VapourSynth，所有运行时、DLL、模型与着色器均随安装包内置分发。
4. **单机隐私与安全**：无商业账号系统与 License 限制，用户凭据全量采用 Windows DPAPI 硬件/账户级加密隔离，零明文落盘。

## 2. 五阶段演进路线图

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│    TTV v1.0     │ ──▶ │    TTV v1.5     │ ──▶ │    TTV v2.0     │
│  Cinema Player  │     │  Smart Library  │     │    AI Cinema    │
└─────────────────┘     └─────────────────┘     └─────────────────┘
         │                                               │
         ▼                                               ▼
┌─────────────────┐                             ┌─────────────────┐
│    TTV v2.5     │ ──────────────────────────▶ │    TTV v3.0     │
│ Private Netflix │                             │  AI 影院系统    │
└─────────────────┘                             └─────────────────┘
```

### 阶段一：TTV v1.0 — Cinema Player (当前目标)
- **播放核心**：Tauri 2 + Rust + `libmpv-2.dll` 动态链接，Direct3D 11 GPU 渲染，HDR Perceptual 色调映射。
- **独立播放窗口**：主界面与独立影院播放窗口分离，支持多窗口生命周期管理与快捷键交互。
- **优先云盘源**：光鸭云盘（Guangya Drive）首发，支持 OAuth2 设备码扫码与短信验证码双登录方式，直链解析与 Range 流式播放。
- **画质增强**：内置 VapourSynth 运行时与 RIFE v4.25 lite ONNX 补帧模型，ArtCNN / SSimDownscaler 超分辨率着色器。
- **数据与安全**：本地独立 SQLite（WAL 模式 + FTS5 全文检索），Windows DPAPI 凭据加密。
- **分发与更新**：GitHub Release 安装包分发，内置全部依赖，支持自定义差分更新与 SHA-256 校验回滚。

### 阶段二：TTV v1.5 — Smart Library
- **元数据刮削**：TMDB、MDBList 本地缓存与海报墙自动匹配。
- **文件扫描**：本地目录、NAS/SMB 路径增量扫描与文件系统变更监听。
- **字幕管理**：内置字幕提取（WebVTT）与 OpenSubtitles / Assrt 在线字幕匹配。

### 阶段三：TTV v2.0 — AI Cinema
- **智能检索**：本地 SQLite FTS5 语义扩展与 AI 模糊搜索。
- **个性化推荐**：基于播放历史与用户偏好的本地轻量推荐引擎。
- **智能片头片尾跳过**：AniSkip、TheIntroDB 协议集成。

### 阶段四：TTV v2.5 — Private Netflix (全源聚合)
- **全网盘矩阵**：阿里云盘、115 网盘、夸克网盘、百度网盘、123 云盘、天翼云盘。
- **媒体服务器**：Emby、Jellyfin、Plex 原生 PlaybackInfo 协议协商与直链提取。
- **网络存储**：WebDAV、飞牛 NAS (fnOS) 适配。

### 阶段五：TTV v3.0 — 终极 AI 影院系统
- **智能画质策略**：根据 GPU 负载自动动态升降级插帧与超分管线。
- **AI 智能字幕与翻译**：离线 Whisper 语音识别与双语字幕实时生成。

## 3. 非目标与边界约束 (Non-Goals)

1. **拒绝商业账号与 License 限制**：TTV 为完全免费的纯单机工具，不设置付费订阅、授权许可（License）与防篡改监视器。
2. **严禁硬编码远端私有服务**：不复刻 LumiPlayer 的 `http://117.72.12.20:9651/api/3` 明文远端解析后端，全部直链解析均由本地 Rust 原生完成。
3. **严禁凭据明文落盘**：绝不允许出现 `direct-cloud-auth.json` 形式的明文 Access/Refresh Token，必须统一经由 DPAPI 加密。
4. **不依赖 Java/Spring Boot**：不引入 102MB 的 Spring Boot fat JAR，本地媒体库与流代理全量由 Rust 原生高性能实现。
