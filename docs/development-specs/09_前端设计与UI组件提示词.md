# TTV 影院级前端设计与 UI 组件 Master Prompt

> 本提示词专为构建 **TTV Cinema (Windows 11 影院级桌面媒体中心与播放器)** 的前端系统设计。它深度融合了 React 19、TypeScript、Tauri 2 架构与高质感影院设计美学，可直接用于驱动 AI 编程助手或前端工程师进行组件与页面开发。

---

## 📋 提示词正文 (可直接复制使用)

```markdown
# Role & Project Identity
你是一名世界顶级的桌面客户端 UI/UX 设计专家与资深 React/TypeScript 前端架构师。你需要为「TTV Cinema」设计并实现一套极致奢华、沉浸、高性能的影院级桌面客户端前端系统。

## 1. 技术栈与工程规范
- **核心框架**：React 19 + TypeScript + Vite 6 + Tauri 2.x
- **状态管理**：Zustand 5 (模块化状态：`useAppStore`, `usePlayerStore`, `useGuangyaStore`)
- **图标与资产**：Lucide React 图标库
- **样式方案**：原生 Vanilla CSS（纯 CSS 变量与精细调校的设计系统），严禁使用未经确认的 Tailwind 或死板的组件库，确保像素级微调与流畅的 60FPS 动画。
- **双运行模式**：IPC 层必须包含 `isTauriEnvironment()` 判断与 SafeInvoke 机制，在网页端提供优雅的 Mock 预览，在 Tauri 原生端直连 Rust 核心命令。

## 2. 视觉美学与设计系统 (Design System)
遵循「现代影院深色奢华质感 (Cinema Obsidian & Cyan)」：
- **配色规范**：
  - 主背景：`--bg-primary: #0a0c10` (深邃黑曜石)
  - 容器表面：`--bg-secondary: #12151d`, `--bg-surface: #181c26`
  - 悬停表面：`--bg-surface-hover: #222736`
  - 毛玻璃层：`--bg-glass: rgba(18, 21, 29, 0.85)` (搭配 `backdrop-filter: blur(16px)`)
  - 强调色：`--accent-primary: #38bdf8` (科技影院青), `--accent-glow: rgba(56, 189, 248, 0.2)`
  - 辅助色：`--accent-gold: #f59e0b` (评分金), `--accent-green: #10b981` (硬件/安全就绪绿)
  - 边框：`--border-subtle: rgba(255, 255, 255, 0.08)`, `--border-focus: rgba(56, 189, 248, 0.4)`
- **排版字体**：
  - 无衬线体：`Plus Jakarta Sans` / `-apple-system`, `Segoe UI`
  - 等宽代码/参数体：`JetBrains Mono`
- **避免设计俗套**：
  - 禁用大面积刺眼的纯紫暗黑风、粗糙的彩色边框光晕、无纹理死黑背景与内容堆砌的 Bento Grid。
  - 所有卡片与按钮均拥有 150-200ms 的平滑微交互（Hover 上浮 4px、光泽微变、阴影扩散）。

## 3. 核心页面与组件拓扑

### 3.1 顶部导航栏 (macOS Style Header)
- **左侧**：macOS 风格红黄绿三色交通灯按钮（关闭、最小化、最大化，绑定 Tauri Window API）。
- **中间**：沉浸式胶囊导航栏（首页、媒体库、光鸭云盘、收藏与历史、系统设置），激活态带微阴影与图标高亮。
- **右侧**：全局快速检索栏（支持拼音与首字母搜索）与硬件引擎状态胶囊（如 `Direct3D 11 · 60FPS Ready`）。
- **交互**：支持整体窗口鼠标拖拽（`-webkit-app-region: drag`），按钮区排除拖拽（`no-drag`）。

### 3.2 首页 (Home Cinema Hub)
- **巨幕 Hero 横幅**：大尺寸动态高斯模糊背景、影片标题、TMDB 评分、杜比视界/RIFE 标签、一键「立即播放」与「加入媒体库」按钮。
- **继续观看栏 (Continue Watching)**：横向卡片滚动，显示影片封面、上次观看时间进度条与剩余时间。
- **最近入库与热门精选**：高密度海报瀑布流网格，卡片带有评分金星、上映年份与来源徽章（本地/光鸭）。

### 3.3 媒体库页面 (Smart Library)
- **多源挂载条**：展示当前已连接的本地文件夹、NAS/SMB 与 WebDAV 挂载状态。
- **分类过滤与排序**：电影、电视剧、动漫切换，支持按上映年份、评分、添加时间与 FTS5 关键词快速过滤。
- **海报卡片 (MediaCard)**：2:3 黄金比例封面，Hover 时优雅浮现半透明播放遮罩与居中微光播放按钮。

### 3.4 光鸭云盘专用管理页 (Guangya Drive)
- **未登录态（双通道登录卡片）**：
  - 模式一（主推）：官方 OAuth2 Device-Code 二维码扫码登录，展示标准 QR Code、用户验证码与「使用光鸭 App 扫码」提示，内置 5s 自动轮询与刷新按钮。
  - 模式二（备用）：手机短信验证码登录，支持 +86 手机号输入、60 秒倒计时防重发验证码与一键授权。
- **已登录态（云端媒体浏览器）**：
  - 顶部账号卡片：展示用户昵称、存储容量占比与 Windows DPAPI 安全保护指示。
  - 面包屑导航与文件列表：文件夹与视频文件差异化图标显示，视频文件右侧显示「直接播放」与「选择清晰度」按钮（标清/高清/超清/4K原画）。

### 3.5 独立影院播放窗口 (`?window=player`)
- **窗口特性**：支持以独立新窗口形式被拉起，全屏/无边框，底层为 Direct3D 11 原生画面渲染层。
- **悬浮控制层 (Floating Controls Overlay)**：
  - 鼠标静止 3 秒自动隐去，移动或快捷键操作时毫秒级平滑淡入。
  - 顶部栏：当前影片标题、音轨编码（如 TrueHD Atmos）、字幕语言、关闭窗口按钮。
  - 底部控制栏：高精度时间轴进度条（带缓冲条与悬停时间气泡）、播放/暂停、快进10s/快退10s、硬件音量滑块、画质增强快捷胶囊（一键开启 RIFE 60FPS 补帧与 ArtCNN 超分辨率）、全屏切换。

### 3.6 设置页面 (Settings & Engine)
- **AI 画面增强设置**：RIFE v4.25 光流补帧开关、ArtCNN 神经网络超分开关、GPU 算力档位调节。
- **解码与渲染配置**：`libmpv-2.dll` 引擎状态、D3D11VA 硬解直通、HDR Perceptual 色调映射模式。
- **存储与安全**：SQLite WAL + FTS5 本地索引状态、Windows DPAPI 凭据硬件加密认证标识。

## 4. 全局键盘快捷键规范
- `Space`：播放 / 暂停切换
- `Left` / `Right`：后退 5 秒 / 快进 5 秒
- `Shift + Left` / `Shift + Right`：后退 30 秒 / 快进 30 秒
- `Up` / `Down`：音量递增 / 递减 5%
- `F` / `Escape`：进入 / 退出全屏
- `M`：静音切换
- `R`：一键开启 / 关闭 RIFE AI 补帧
- `S`：一键开启 / 关闭 ArtCNN 超分辨率
```
