# 网盘登录协议矩阵

更新日期：2026-08-21

| 来源 | 当前登录方式 | 主窗口二维码 | 文件/视频 | 说明 |
| --- | --- | --- | --- | --- |
| 光鸭云盘 | RFC 8628 device-code | 自动轮询 | 已支持 | 官方 device-code、token 轮询、目录和视频地址均由 Provider 适配器完成 |
| 百度网盘 | 官方 OAuth 授权码 | 已支持 | 已支持 | 使用本应用登记的 Client ID；二维码、授权码回填、目录列表和下载地址均留在主窗口 |
| 阿里云盘 | 官方 OAuth 授权码 | 已支持 | 已支持 | 使用本应用登记的 Client ID；目录与下载地址走开放 API |
| 天翼云盘 | 官方 OAuth 授权码 | 配置后显示 | 待适配 | 未配置 Client ID 时不生成无效二维码 |
| 123 云盘 | 待确认的官方 OAuth | 配置后显示 | 待适配 | 当前不复用其他应用的客户端标识或网页会话 |
| 夸克网盘 | 私有网页/CAS 会话 | 不显示模拟码 | 不支持 | 不复制 Cookie、设备指纹、私有 CAS 或签名流程 |
| 115 网盘 | 私有网页会话 | 不显示模拟码 | 不支持 | 不复制网页会话、客户端密钥或私有下载签名 |

后端提供统一的 `provider_qr_login_create` / `provider_qr_login_poll` 接口。Provider 明确配置官方 `deviceCodeEndpoint`、`deviceCodeGrantType` 和 `clientId` 时，前端在右侧卡片中显示二维码并自动轮询；仅提供授权码 OAuth 的来源，则在同一卡片中显示官方授权 URL 二维码和授权码输入。项目不再创建云盘登录子窗口，也不会导入网页 Cookie/CAS 会话。
